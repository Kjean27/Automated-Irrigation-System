# Bill of Materials

Every part required to assemble the Automated Irrigation System (AIS) is cataloged here. Gather these components before beginning your assembly.

> [!NOTE]
> Component pricing and availability may change frequently. Standard 1/4" drip tubing and fittings can be sourced from local hardware stores or online suppliers.

---

## Core Electronics & Controls

| Item | Qty | Notes |
| :--- | :--- | :--- |
| **Arduino Nano (Type-C)** | 1 | Primary microcontroller managing logic and pinouts |
| **Nano Terminal Adapter** | 1 | Breakout board for secure screw-terminal wiring |
| **1-Channel 5V Relay Module** | 1 | Active High/Low level trigger controlling the water pump |
| **Tactile Button Switch Assortment** | 4 | Colorful round caps for **M**, **R**, **+**, and **-** inputs |
| **Basic 5mm LEDs (Blue or preferred color)** | 7 | Form the circular status array |
| **Resistors - 100 Ω (1/4W)** | 7 | Current-limiting resistors for individual LEDs |
| **Resistors - 10k Ω (1/4W)** | 4 | Pull-down/pull-up resistors for tactile buttons |
