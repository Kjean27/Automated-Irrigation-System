# CAD Files

3D CAD models for the AIS - Automated Irrigation System controller enclosure. Files are provided in STL format for direct 3D printing and were designed in Onshape.

> [!CAUTION]
> If you swap out internal components (like using a different relay module, battery, or larger microcontroller), you may need to adjust hole placements and mounting post dimensions before printing.

## How to Edit or Modify the Design

You do not need paid software to customize this controller. Here are the easiest ways to edit the files based on what software you use:

1. **Onshape (Recommended)** – Since the controller was originally designed in Onshape, you can easily copy the workspace or import the STl files into a free Onshape account. It runs completely in your browser without requiring a powerful computer.
2. **Fusion 360 (Personal License)** – Import the `.stl` files into Autodesk's free hobbyist version. This allows you to easily modify the shell thickness, adjust button tolerances, or move the LED ring cutouts.
3. **FreeCAD** – Open the `.stl` files using the free, open-source *Part Design* workbench to adjust mounting posts and hole diameters parametrically.
4. **Blender or Bambu Studio / PrusaSlicer (Quick Tweaks)** – If you only need to add text, resize button clearances, or modify surface aesthetics, import the `.stl` directly into your slicer or Blender for rapid cosmetic adjustments.

> [!TIP]
> Always keep a backup copy of the original CAD files. Make your changes on a duplicate file so you can easily reference original measurements if a print doesn't line up.
